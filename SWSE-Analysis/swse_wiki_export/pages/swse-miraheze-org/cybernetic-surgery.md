# Cybernetic Surgery

> Source: [https://swse.miraheze.org/wiki/Cybernetic_Surgery](https://swse.miraheze.org/wiki/Cybernetic_Surgery) · Retrieved 2026-10-09T09:36:29Z.

*Reference Book: [Core Rulebook](https://swse.miraheze.org/wiki/Core_Rulebook "Core Rulebook")*

You can perform the surgical procedures necessary to graft cybernetic components onto living flesh.

**Prerequisite:** [Trained](https://swse.miraheze.org/wiki/Trained "Trained") in [Treat Injury](https://swse.miraheze.org/wiki/Treat_Injury "Treat Injury")

**Effect:** You can install [Cybernetic Prostheses](https://swse.miraheze.org/wiki/Cybernetic_Prostheses "Cybernetic Prostheses") on living beings. The surgical procedure takes 1 hour of uninterrupted work, after which you must make a DC 20 [Treat Injury](https://swse.miraheze.org/wiki/Treat_Injury "Treat Injury") check. If the check succeeds, the [Cybernetic Prosthesis](https://swse.miraheze.org/wiki/Cybernetic_Prosthesis "Cybernetic Prosthesis") is installed correctly. If the check fails, the device is not properly installed; however, you can try again after another uninterrupted hour of [Surgery](https://swse.miraheze.org/wiki/Surgery "Surgery").

**Special:** You can install a [Cybernetic Prosthesis](https://swse.miraheze.org/wiki/Cybernetic_Prosthesis "Cybernetic Prosthesis") on yourself, but you take a -5 penalty on the [Treat Injury](https://swse.miraheze.org/wiki/Treat_Injury "Treat Injury") skill check. If you have the [Surgical Expertise](https://swse.miraheze.org/wiki/Surgical_Expertise "Surgical Expertise") feat, you can install a [Cybernetic Prosthesis](https://swse.miraheze.org/wiki/Cybernetic_Prosthesis "Cybernetic Prosthesis") in 10 minutes instead of 1 hour.

# Character Sheet

> Source: [https://swse.miraheze.org/wiki/Character_Sheet](https://swse.miraheze.org/wiki/Character_Sheet) · Retrieved 2026-10-09T09:36:19Z.

When recording information during [Character Creation](https://swse.miraheze.org/wiki/Character_Creation "Character Creation") and beyond, you need a Character Sheet to contain its information. The following Character Sheets are suitable for such a task:

- [File:Character Sheet.pdf](https://swse.miraheze.org/wiki/File:Character_Sheet.pdf "File:Character Sheet.pdf") - The standard Character Sheet included in the *[Core Rulebook](https://swse.miraheze.org/wiki/Core_Rulebook "Core Rulebook")*
- [File:Character Sheet(alt).pdf](https://swse.miraheze.org/wiki/File:Character_Sheet(alt).pdf "File:Character Sheet(alt).pdf") - A simplified Character Sheet with core abilities contained on page 1 (creator unknown)
- [File:Vehicle Sheet.pdf](https://swse.miraheze.org/wiki/File:Vehicle_Sheet.pdf "File:Vehicle Sheet.pdf") - A Vehicle Sheet to record a party's [Vehicles](https://swse.miraheze.org/wiki/Vehicles "Vehicles") (created by edoc user "Tam")
- [SagaForge Character Sheet](https://drive.google.com/drive/folders/1goVZENdI61gTyHy165p_ocoKpE60lk4A) - A digital Character Sheet and digital index using Excel (created by "Ultramyth/NotLestat")
- [Excel Character Sheet](http://www.mediafire.com/file/ubt83285t6oljwh/CharSheet%26CombatTool_v210a_%28Statblock_tab_has_all_NPC%27s%2C_droids%2C_beasts_stats%29.xls) - A digital Character Sheet using Excel (created by "Old Benn")
- [File:Character Sheet(MI).pdf](https://swse.miraheze.org/wiki/File:Character_Sheet(MI).pdf "File:Character Sheet(MI).pdf") - A digital Character Sheet for [Roll20.net](https://roll20.net/) (GitHub user "alicia86"; based on work by "Madirishman")
